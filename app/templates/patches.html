Roll back

Undoes that rollout: an added patch is deleted again, an edit goes back to the previous text and target, a deleted patch comes back. The nodes follow, with the same dry run and checks. Only possible while the patch is still exactly as that rollout left it.

Sync nodes to their baseline

No patch changes: the selected nodes get their config as the baseline describes it (role config plus their patches), which removes any drift. Nodes that drift are preselected.
